# MissFisher ICE Scheduler

在 MissFisher 的钓鱼等待间隙运行 ICE，并在下一目标窗口前停止 ICE、切回捕鱼人及恢复所选 MissFisher 目标。

## 依赖

- Dalamud API 15
- MissFisher 2.3.1.x 或 2.4.0.0
- ICE 1.0.0.2000
- ICE 正常运行所需的 vnavmesh、Artisan、AutoHook 等插件

ICE 只能在它支持的宇宙探索区域运行。调度器不会修改 ICE 的任务配置；请先在 ICE 中配置并验证其任务模式，并在调度器中选择 ICE 启动时使用的生产/采集套装。

停止周期时，调度器会同时停止 ICE 自身调度与 ICE 已交给 Artisan 的制作队列，并在两者都稳定空闲后才切回捕鱼人。若停止确认超时，会继续重试而不会在 Artisan 仍制作时提前恢复 MissFisher。

可启用“自动选择未满级生产/采集职业”。调度器会从具有有效套装、未被排除且低于等级上限的职业中选择目标，默认按最低等级优先。ICE 运行期间若当前职业达到 100 级，会等待当前任务完成、停止 ICE、切换下一个职业并重新启动；若某职业在当前区域无法领取练级任务，则在本周期跳过。可配置是否包含捕鱼人以及排除任意职业。

默认开启“切换职业后穿上最强装备（不保存套装）”。每次切换到 ICE 使用职业后，调度器会调用游戏原生推荐装备功能，装备当前兵装库中的最强可用装备，但不会覆盖原套装，然后再启动 ICE。

默认在启动 ICE 前检查当前已装备物品的耐久，最低耐久不高于 30% 时调用游戏原生自修功能。ICE 长时间运行中达到阈值时，会等待当前任务完成、停止 ICE、修理并重新启动。此流程只修理当前装备，需要背包中有足够暗物质，并且对应生产职业达到装备要求的修理等级；阈值可在配置页调整。

停止 ICE 时，调度器会以游戏的实际合成界面、制作技能执行和准备制作作为安全信号。ICE 已停、Artisan 停止请求已生效，且连续 5 秒没有实际合成时，即使 `Artisan.IsBusy` 因内部制作状态残留仍为 true，也会继续恢复捕鱼。真实合成仍在进行时不会强行切换职业。停止阶段的完整判定每 10 秒写入 Dalamud 日志，便于定位后续的 ICE 或 Artisan 状态异常。

如果在 Artisan 正在合成时进入停止阶段，调度器会先停止 ICE，但不会用 Artisan 停止请求把当前合成冻结在等待下一个技能的界面。它会仅让 Artisan 完成当前一件，然后在合成界面关闭的空档立即停止 Artisan 并恢复 MissFisher。

默认使用内置月球入口流程，不依赖快捷传送面板或 `/tp` 命令：调度器通过稳定的以太之光 ID `175` 调用游戏传送服务前往“最佳兔威洞”，通过 vnavmesh 移动到已确认的入口世界坐标，查找并与“驾行威”交互，自动推进对话和确认。传送请求未生效时会自动重试，只有严格确认已经进入所选 ICE 区域后才会切换职业并启动 ICE。

内置流程可在配置中关闭。关闭后仍可使用“跨区步骤命令（用 || 分隔）”调用其他插件提供的传送、寻路和交互命令。

默认开启“只观察”。输入 `/mfice` 打开主界面。界面分为“状态 / 配置 / 日志”三页：状态页负责启动、停止和完整流程测试，配置页保存调度参数，日志页可直接查看或复制最近 300 条关键事件。

## 命令

```text
/mfice enable
/mfice disable
/mfice abort
/mfice reset
/mfice status
```

## 完整流程测试

1. 先在 ICE 的 Agenda 中，为调度器所选区域和职业启用至少一个当前可执行的任务。
2. 启动之后需要恢复的 MissFisher 目标，并让角色处于捕鱼人、非战斗和非传送状态；ICE 保持停止。
3. 确认 vnavmesh 已启用并完成入口地图构建。
4. 打开状态页，点击“完整测试一次”。此操作不受钓鱼等待阈值和“只观察”设置限制。
5. 调度器会依次暂停 MissFisher、进入目标区域、启动 ICE，并通过 ICE IPC 设置“完成当前任务后停止”。实际领取并完成一个任务后，再恢复原捕鱼套装和 MissFisher 目标。

如果 ICE 启动后立即停止且任务 ID 始终为 0，调度器会明确提示当前 Agenda 对所选区域和职业没有可执行任务，并暂停自动重试 5 分钟，避免反复传送。

插件会先处理驾行威的入口操作菜单，再打开游戏专用的 `WKSPlanetSelect` 目的地界面。配置可选择憧憬湾、法恩娜、俄匊斯和奥克塞西亚，默认是憧憬湾（Sinus Ardorum）。调度器会逐步切换星球，读取界面名称确认目标后，才点击“移动”并等待换区。

暂停 MissFisher 后，调度器会等待其已经发出的传送完成，并确认角色与区域稳定后才启动 ICE 旅行，避免两套传送流程互相覆盖。

国服的 `WKSPlanetSelect` 使用专用交互事件，静态节点中不暴露普通按钮。调度器分别使用星球切换事件和“移动”事件，并在每次切换后重新读取标题，避免把切换星球误判成确认移动。
